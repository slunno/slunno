# Protótipos demonstrativos

Os arquivos deste diretório são demonstrações visuais e independentes do **AKR Moda** e do **AKR Chat**.

- Use somente os arquivos HTML correspondentes para hospedar cada demo em um serviço estático.
- Para visualizar localmente, baixe o arquivo `index.html` e abra-o no navegador.
- Os dados e perfis exibidos são fictícios.
- Os protótipos não se conectam a APIs, bancos de dados, autenticação ou serviços corporativos.
- O AKR Chat mantém as mensagens apenas na memória da aba durante a sessão.
